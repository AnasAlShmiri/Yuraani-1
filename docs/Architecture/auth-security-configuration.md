# إعدادات أمان المصادقة

## مفاتيح البيئة

لا تضع المفاتيح السرية داخل ملفات الإعدادات أو مستودع Git.

اضبط المتغيرات التالية في بيئة التشغيل:

- `Verification__HashKey`: مفتاح عشوائي سري لا يقل عن 32 بايت لحماية رموز التحقق باستخدام HMAC-SHA256.
- `Jwt__Secret`: مفتاح توقيع JWT لا يقل عن 32 بايت.
- `Jwt__Issuer`: الجهة المصدرة للرمز.
- `Jwt__Audience`: الجهة المستقبلة للرمز.

مثال PowerShell لإنشاء مفتاح عشوائي (احتفظ بالناتج خارج المستودع):

```powershell
[Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(48))
```

يمكن استخدام ناتج مستقل لكل من `Verification__HashKey` و`Jwt__Secret`.

## تحديث قاعدة البيانات

قبل تشغيل النسخة التي تتضمن حماية رموز التحقق، نفّذ:

`src/Yuraani.Infrastructure/Persistence/Migrations/20261112_AddVerificationChallengeProtection.sql`

يضيف التحديث `AttemptCount` و`RevokedAt` إلى جدول `VerificationChallenges`.

## حدود الحماية الحالية

- حد محاولات الرمز: 5 محاولات لكل رمز.
- صلاحية الرمز: 10 دقائق.
- حد طلبات مسارات المصادقة: 10 طلبات لكل عنوان IP خلال دقيقة واحدة.
- محدد الطلبات الحالي داخل الذاكرة؛ عند تشغيل عدة نسخ من API يجب استخدام مخزن موزع.
- يجب ضبط مزود SMS والبريد الفعلي قبل الإنتاج؛ المرسل الحالي مخصص لبيئة التطوير.
